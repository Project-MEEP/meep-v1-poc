# Project MEEP — rules

This repository is PUBLIC. There must NEVER be PII in it: no real names, personal
emails, phone numbers, addresses, account IDs, API keys, tokens, or credentials —
in code, docs, comments, commit messages, issues, or PRs.

- Commit identity is the GitHub noreply address only.
- Use placeholders/fake data (e.g. user@example.com) for examples and tests.
- Before any commit, scan the staged diff for PII; a pre-commit hook also checks.
- If PII is ever committed, stop and tell the owner; history must be rewritten.
