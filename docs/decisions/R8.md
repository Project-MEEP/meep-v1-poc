# R8: Deleting a name while the change log is append-only

- **ID:** R8
- **Status:** Confirmed
- **Date:** 2026-11-19
- **Owner:** Owner decision (spec Readiness table)

## Decision

Crypto-shredding: each record's content is encrypted with its own key; deleting destroys the key, and the log keeps only "a name was deleted" with the date.

Built in the v1.0 foundation so later features (card images, documents, journal) inherit a real "delete means gone" guarantee.
