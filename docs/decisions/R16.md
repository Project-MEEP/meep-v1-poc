# R16: Address segment syntax

- **ID:** R16
- **Status:** Confirmed
- **Date:** 2026-11-19
- **Owner:** Owner decision (spec Readiness table)

## Decision

Exactly five dot-separated segments; each starts with a letter and contains only letters, digits and hyphens; case is kept for display and ignored for comparison.

## Clarification (owner-confirmed 2026-11-22)

"Letters" means ASCII letters (A to Z and a to z), and "digits" means ASCII digits. This gives "case ignored for comparison" a single meaning and excludes look-alike (confusable) characters from other scripts.

See FOUND-13 (registered addresses).
