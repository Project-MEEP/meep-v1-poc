# NAMES-07: Keystone changes need explicit confirmation

- **ID:** NAMES-07
- **Status:** Confirmed

## Decision

Keystone changes (changing or retiring the Legal name, and other identity-defining edits) require an explicit confirmation step and raise a toast (UI-02) plus an entry in the notifications tray (UI-03).

## Notes

The list of "other identity-defining edits" is not yet enumerated. Spec 001 and its tasks are not yet amended. "Replace everything" in the foundation's restore uses this confirmation pattern (checklist CHK034).
