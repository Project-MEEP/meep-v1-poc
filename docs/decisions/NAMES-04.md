# NAMES-04: Short form of a name

- **ID:** NAMES-04
- **Status:** Confirmed
- **Date:** 2026-11-19
- **Owner:** Owner decision (spec 001 clarification)

## Decision

1. Set per name in "More name options" on the Add or edit a name screen, labeled by purpose (for example "Short name: shown where space or privacy calls for it"), with the computed default (R15) as the placeholder.
2. The owner may enter anything; only the length rules apply.
3. Display value only: never used for matching and never included in outbound exports.
4. The short form displayed is the Preferred name's, or the Legal name's if there is no Preferred name (R15).
