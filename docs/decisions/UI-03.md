# UI-03: The notifications tray keeps timestamped, dismissible entries

- **ID:** UI-03
- **Status:** Confirmed
- **Date:** 2026-11-20
- **Owner:** Owner

## Decision

The notifications tray keeps timestamped entries. Entries are dismissible. Every dismissal is recorded in the History log (LOG-01 item 7).

## Notes

The foundation records dismissals as kind `notice_dismissed` (spec 002 FR-049, T136); the tray screen belongs to spec 010. LOG-01 already cited UI-02 and UI-03 before these records existed.
