# PRON-01a: Pronoun visibility in v1.0

- **ID:** PRON-01a (clarifies PRON-01)
- **Status:** Confirmed
- **Date:** 2026-11-19
- **Owner:** Owner decision (clarification of spec 001, names)

## Decision

1. Visibility choices shown in v1.0: "Only me" or "Included in exports". "Delegates" is added when delegates exist (a later version); the stored setting can hold it, but it is not shown in v1.0.
2. "Exports" means outbound exports only (the US health-data name form and the standard healthcare name format). The owner backup and backup always includes pronouns regardless of this setting (principle 27, no lock-in).
3. When pronouns are first enabled, visibility defaults to "Only me".

Note: principle 27 is now Confirmed in the constitution (CONST-27).
