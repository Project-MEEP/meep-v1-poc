## Decision

Adopt [docs/standards/NAMING.md](../standards/NAMING.md) as the naming standard for decision records, spec-local and global IDs, specs and documents, Git and GitHub, Rust code, messages and logs, and words people see.

Rule zero: codify what exists. Renaming existing things is a separate, explicit task, never a side effect of other work.

## Notes

- Proposed until the owner confirms. The standard itself says what is already the existing pattern.

- Existing items that do not match the standard are reported in the PR body, not changed.
