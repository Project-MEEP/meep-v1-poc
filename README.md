# Meep

Meep is a free, MIT-licensed, user-owned system of record and coordination. It
takes the administrative work of care off patients, families and caregivers. It
is not a clinician, pharmacy, legal verifier or EHR, and it claims no authority
over any record it holds.

> Meep is always free. We will never charge you, call you, or ask for your
> passwords or insurance login. If "Meep" asks for your password in a chat, it's
> fake.

## Status

Pre-alpha. Nothing here is ready to use. The current target is **v1.0**: an app
shell with the full names feature, written in Rust, web first.
