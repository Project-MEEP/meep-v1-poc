# Security policy

## Reporting a vulnerability or a fake

Please report privately using GitHub's "Report a vulnerability" button on the
Security tab of this repository. Do not open a public issue for a security
problem.

To report a fake or lookalike "Meep" (a build, site or message that is not from
this project), use the same private channel.

## Genuine releases

Genuine releases are signed and verifiable (see the spec, DIST-01). Only trust
builds published from this repository.

## Notice

Meep is always free. We will never charge you, call you, or ask for your
passwords or insurance login. If "Meep" asks for your password in a chat, it's
fake.
